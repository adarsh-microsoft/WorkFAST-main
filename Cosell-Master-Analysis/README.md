## 🔄 How to refresh / extend

1. **Re-pull inventory** after repo changes, then run
   `pwsh -File data/gen-inventory-data.ps1` to regenerate `report/inventory-data.js`.
2. **Run a hygiene wave** (per area) via the WorkFast / `fabric-devops` subagent using the
   PR-Review skill, then append confirmed findings to `report/analysis-data.js`
   (`anomalies[]`, `hygiene.spineFindings[]`) and flip the wave `status` to `Done`.
3. The `memory/` and `anomalies/` markdown files mirror the same data for
   diff-able, reviewable history.
