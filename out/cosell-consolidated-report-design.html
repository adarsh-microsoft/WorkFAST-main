§ Data Model Notes — CosellSemanticModel

DM

Key tables & relationships

Star-schema overview, role-playing dimensions, RLS
▶

Likely table groups (inferred from report usage)

  • fact
    Fact_Opportunity / Fact_Pipeline
    Grain: opportunity × snapshot date. Holds ACV/TPV, stage, owner, dates.
  • fact
    Fact_BilledRevenue
    Grain: invoice line. Bill date, amount, currency, partner attribution.
  • fact
    Fact_Consumption (ACR)
    Grain: subscription × month. Azure Consumed Revenue per customer.
  • fact
    Fact_PartnerReportedACR
    Partner-submitted ACR with validation status.
  • dim
    Dim_Partner
    MPN ID, Tier (Co-sell Ready / Prioritized), Type (IP / Services).
  • dim
    Dim_Customer
    TPID, Segment, Industry, Geo.
  • dim
    Dim_Solution / Dim_Workload
    Solution Area hierarchy + Power 5 mapping flag.
  • dim
    Dim_Date
    Mark as date table; FY/FQ/FM hierarchy aligned to Microsoft fiscal calendar (Jul–Jun).
  • dim
    Dim_Geography / Dim_Area
    Area → Subsidiary → Region hierarchy.

Relationships & security

  • rel
    Single-direction filtering
    Dimensions → facts. Avoid bi-directional unless required for partner-customer many-many.
  • rls
    Row-Level Security
    Likely Area-based RLS — verify and document at publish time. Confirm if HQ/WW role exists.

§ Risks & Open Questions

Power 5 report metadata unreadable — the source report returned ExplorationFormatVersionError from the Power BI REST API. Visual list inferred from the report name only. Action: open in Power BI Desktop and confirm visual inventory before consolidating.
Visual-level metadata not extracted — the GetReportMetadata tool failed with a JSON parser error on all 6 readable reports. Visual recommendations are inferred from page titles + domain patterns; should be validated against live reports during build.
RLS verification needed — assumption is Area-based RLS. Confirm with the dataset owner whether HQ/WW roles exist and how partner-org users are scoped.
Deprecation plan — propose 60-day overlap where source reports remain alongside the consolidated report; gather usage telemetry before sunsetting.
